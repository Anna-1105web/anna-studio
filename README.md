# ANNA.STUDIO — односторінковий сайт

Статичний сайт без збірки: `index.html` (HTML + CSS + JS в одному файлі), скриншоти робіт у `assets/portfolio/`, фото Анни в `assets/img/` (`anna-portrait.webp` — портрет у блоці «Про мене», `anna-avatar.webp` — аватар на першому екрані), `robots.txt`.

На Vercel розгортається як є: Framework Preset — **Other**, Build Command — порожньо, Output Directory — корінь проєкту.

## Запуск локально
Відкрийте `index.html` у браузері. Або запустіть локальний сервер у папці проєкту:
```
python3 -m http.server 8000
```
і перейдіть на http://localhost:8000

## Налаштування (внизу index.html, об'єкт CONFIG)
```js
const CONFIG = {
  formEndpoint: "https://formspree.io/f/XXXXXXX"
};
```
- Telegram (@anna_websitee) та Instagram (@anna.webstudio) уже прописані в HTML: на першому екрані, у мобільному меню, у блоці контактів і в футері.
- Поки `formEndpoint` порожній, форма НЕ надсилає дані й пропонує написати в Telegram/Instagram.

### Підключення форми (Formspree, безкоштовний план)
1. Зареєструйтеся на formspree.io → New Form → скопіюйте адресу виду `https://formspree.io/f/abcdwxyz`.
2. Вставте її в `formEndpoint`.
3. Надішліть тестову заявку й підтвердіть email у Formspree.
Поля, що надсилаються: `name`, `contact`, `site_type`, `plan`, `message` (+ антиспам-поле `_gotcha`).
Підійде й будь-який інший сервіс, що приймає POST з FormData (Getform, Basin, власний бекенд).

## Публікація
**Vercel:** vercel.com → Add New → Project → завантажте папку (або підключіть GitHub-репозиторій) → Framework: Other → Deploy.
**Netlify:** app.netlify.com/drop → перетягніть папку проєкту.
**GitHub Pages:** завантажте файли в репозиторій → Settings → Pages → Branch: main / root.
Власний домен підключається в налаштуваннях обраного хостингу (Domains).

## Що замінити за потреби
- Описи робіт і бейджі «Концепт» / «Демо-проєкт» — у секції `#portfolio`.
- Скриншоти — `assets/portfolio/*.webp` (1200×749).
- Фото — `assets/img/anna-portrait.webp` (формат 4:5; для максимальної чіткості на Retina бажано оригінал ширше 700 px).
- Після підключення домену додайте в `<head>` `<link rel="canonical" href="https://ваш-домен/">` і зробіть `og:image` повною адресою.
- Кольори — змінні на початку `<style>` (`--bg`, `--card`, `--accent` тощо).
- Тексти «Про мене» — у секції `#about`.

## Що потребує погодження
Блок «Умови для всіх тарифів» (секція `#pricing`) містить тимчасові формулювання, позначені `data-todo` і коментарями `<!-- TODO Анна -->`:
терміни виконання, кількість правок, наповнення контентом, підтримка після запуску.
Щоб побачити їх підсвіченими, відкрийте сторінку з `?todo` в кінці адреси (напр. `index.html?todo`).
Після заміни тексту видаліть атрибут `data-todo`.

## Мови (UA · EN · PL · RU)
- **Тексти всіх мов** — у файлі `assets/js/i18n.js`. Кожен запис має ключ (напр. `"k009"`) і чотири варіанти: `uk`, `en`, `pl`, `ru`.
  Щоб змінити текст — відредагуйте рядок потрібною мовою. Ключ підказує атрибут `data-i18n="k009"` в `index.html`.
- `meta.*` — заголовок і опис сторінки для пошуковиків; `ui.*`, `err.*`, `st.*`, `form.*` — меню, помилки й повідомлення форми.
- Мова перемикається без перезавантаження, вибір зберігається в браузері (localStorage).
- Українська — мова за замовчуванням (`/`). Окремі сторінки для SEO: `/en/`, `/pl/`, `/ru/` (файли `en/index.html` тощо).
  На Vercel вони працюють без жодних налаштувань; при перемиканні мови адреса в браузері змінюється на відповідну.
- Кожна сторінка має свій `lang`, `title`, `description`, `og:locale`, а також `hreflang` і `canonical`.
- Заявки з форми приходять з українськими значеннями «Тип сайту» незалежно від мови відвідувача, плюс поле `lang` — мова, якою користувався клієнт.

### Після підключення домену
`hreflang` і `canonical` зараз мають відносні адреси (`/`, `/en/`…). Пошуковики радять повні адреси з доменом —
надішліть мені домен, і я згенерую мовні сторінки з ним (а також `sitemap.xml`).

### Якщо змінили тексти в i18n.js
На сайті зміни видно одразу всіма мовами. Статичні сторінки `/en/`, `/pl/`, `/ru/` для пошуковиків варто перегенерувати —
це робиться скриптом, попросіть мене.
